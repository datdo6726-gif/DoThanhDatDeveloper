# Đỗ Thành Đạt Developer Profile

## Build bằng GitHub Actions
1. Upload toàn bộ thư mục này lên repository GitHub.
2. Vào tab **Actions**.
3. Chọn **Build iOS IPA**.
4. Bấm **Run workflow**.
5. Sau khi chạy xong, tải artifact `DoThanhDatDeveloper-unsigned-ipa`.

Lưu ý: IPA này là unsigned, dùng để kiểm tra build. Muốn cài lên iPhone thật cần ký bằng Apple Developer certificate/provisioning profile hoặc dùng dịch vụ signing hợp lệ.
